# 新增资料登记模板

在 `data/course.ts` 的 `materials` 数组中复制以下结构，并替换内容：

```ts
{
  id: 'm13',
  title: '资料中文标题',
  chapter: 3,
  week: 3,
  type: '课件',
  format: 'PDF',
  size: '2.0 MB',
  path: '/course-materials/course-001/chapter-03/slides/file-name.pdf',
  summary: '用一句中文说明这份资料的用途。',
  keywords: ['第三章', '回归', '课件', '复习'],
}
```

资料类型应使用：`课件`、`阅读`、`练习`、`案例` 或 `视频`。
