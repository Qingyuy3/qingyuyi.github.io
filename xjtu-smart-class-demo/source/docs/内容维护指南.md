# 数智课堂 Demo 内容维护指南

本项目是“西安交通大学管理学院 · 数据分析与商业决策”单门课程子站 Demo。所有课程名称、学生、教师、日期、成绩和资料均为演示内容。

## 最常修改的三个位置

1. `data/course.ts`：课程名称、章节、资料登记、小测题目和公告。
2. `public/course-materials/course-001/`：实际 PDF、PPT、Word、Excel、视频等课程文件。
3. `components/course-views.tsx`：各个页面展示的文字和布局。

## 添加课程资料

以第三章“回归分析导论”课件为例：

1. 把真实文件放到：
   `public/course-materials/course-001/chapter-03/slides/regression-introduction.pdf`
2. 打开 `data/course.ts`，在 `materials` 列表中找到对应条目。
3. 修改标题、简介、文件大小、关键词和路径。
4. 在网站“资料中心”搜索“回归”或“第三章”，检查结果是否正确。

## 文件夹含义

- `slides`：课堂课件。
- `readings`：阅读资料、论文或概念速查表。
- `exercises`：练习题、数据表和模板。
- `cases`：案例正文与案例数据。
- `answers`：参考答案，正式网站中建议设置教师权限。
- `videos`：课程视频。

## 文件命名建议

- 使用小写英文和短横线，例如 `regression-introduction.pdf`。
- 不使用空格、中文括号或“最终版2”等难以维护的名称。
- 同类文件可加版本或日期，例如 `regression-practice-v2.xlsx`。
- 文件更名后，一定同步修改 `data/course.ts` 中的 `path`。

## AI 资料助手如何工作

当前 Demo 不连接付费 AI。它会读取 `data/course.ts` 中每份资料的标题、章节、周次、类型和 `keywords`（关键词），然后返回匹配结果。

为了让资料更容易被找到，请为每份资料加入：

- 章节表达：`第三章`、`第3章`。
- 主题表达：`回归`、`线性回归`。
- 用途表达：`练习`、`复习`、`案例`。
- 常见同义词或学生可能使用的问法。

未来如需真正读取 PDF 内容并回答问题，可升级为 RAG（检索增强生成）：先从真实课程文件中检索相关段落，再由 AI 组织回答并标注来源。

## 小测与作业上传

- 小测题目位于 `data/course.ts` 的 `quizQuestions`。
- 每题包含问题、四个选项、正确答案序号和中文解释。
- 当前作业上传只演示选择、拖入和提交状态，不把文件发到服务器。
- 正式使用时需要学生登录、数据库、文件存储和教师批改权限。

## 发布说明

项目可以放入 GitHub 进行版本管理，但 GitHub 链接本身不是网站。网站需要再发布到托管服务。本 Demo 使用 Sites 发布，维护人员仍可将整个项目同步到 GitHub。
