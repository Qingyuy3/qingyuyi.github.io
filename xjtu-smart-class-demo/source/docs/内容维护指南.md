# 数智课堂 Demo 内容维护指南

本项目是“西安交通大学管理学院 · 智能分析”单门课程子站 Demo。当前页面使用历年教学包整理课程知识结构；新学期日期、地点、提交状态和学生讨论仍是演示信息。

## 最常修改的三个位置

1. `data/course.ts`：课程信息、8 个学习单元、19 份资料登记、小测题目、作业和公告。
2. `public/course-materials/course-001/`：实际 PDF、CSV、Notebook 和代码文件。
3. `components/course-views.tsx`：各页面展示文字与布局。

## 当前资料结构

```text
public/course-materials/course-001/
└─ former-semester-2024/
   ├─ 课件/    10 份 PDF
   ├─ 作业/     4 份 PDF
   ├─ 数据/     tips.csv、titanic.csv
   └─ 代码/     2 份 Notebook、1 份 Python 示例
```

网站没有简单照搬文件名，而是按照知识依赖重排为：课程概述 → R 基础与可视化 → Python/NumPy/Pandas → 集成学习 → 静态和动态爬虫。

## 添加课程资料

以新增一份“Pandas 缺失值处理”课件为例：

1. 把文件放入对应学期目录，例如：
   `public/course-materials/course-001/semester-2026/课件/pandas-missing-values.pdf`
2. 打开 `data/course.ts`，在 `materials` 列表中复制一个条目。
3. 修改标题、单元、格式、文件大小、路径、摘要和关键词。
4. 在网站“资料中心”搜索“Pandas”“缺失值”或“第五单元”，检查结果并打开文件链接。

## AI 资料助手如何工作

当前 Demo 不连接付费 AI。它根据资料标题、单元、类型、格式、摘要和关键词进行本地匹配，不会上传学生问题。

关键词建议同时包含：

- 单元表达：`第五单元`、`第5章`。
- 主题表达：`Pandas`、`透视表`、`数据清洗`。
- 文件用途：`课件`、`作业`、`数据`、`代码`。
- 常见问法：`Python 基础`、`网络爬虫练习`、`Tips 数据`。

未来如需真正读取 PDF 内容并回答问题，可以升级为 RAG（Retrieval-Augmented Generation，检索增强生成）：先从真实文件中检索相关段落，再由 AI 组织答案并标注来源。

## 小测与作业上传

- 小测题目位于 `data/course.ts` 的 `quizQuestions`。
- 作业列表位于 `assignmentTasks`，当前对应 4 份历年原题。
- 作业上传只演示选择文件和提交状态，不会把文件发送到服务器。
- 正式使用需要学生登录、数据库、文件存储、截止时间与教师批改权限。
